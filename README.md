# 👗 Smart Tailor 2.0

A smart tailoring and outfit recommendation web application built with React and Express.

## 📌 About the Project

Smart Tailor 2.0 is a web application designed to help users explore outfit ideas and customize dress styles. Users can upload outfit inspiration images, select preferences, and receive recommendations based on their selections.


## 📸 Application Preview

![Smart Tailor 2.0 Homepage](screenshots/homepage.png)

## ✨ Features

* **Image Upload:** Upload and preview outfit inspiration images.
* **Outfit Recommendations:** Get recommendations based on selected preferences.
* **Style Preferences:** Choose skin tone and body type.
* **Dress Customization:** Explore dress colors, necklines, and sleeve styles.
* **Pinterest Inspiration:** Add an inspiration link.
* **Design Notes:** Keep track of selected customization options.

## 🚀 Getting Started

### Prerequisites

* Node.js and npm
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/prathibayemma/smart-tailor-2.0.git
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-tailor-2.0
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the backend server in one terminal:

   ```bash
   npm run server
   ```

5. Start the frontend in a second terminal:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed by Vite in your browser.
